# 首板次日高开研究器设计

## 目标

研究沪深主板“当日首板涨停”的启动特征，找出“T 日尾盘买入、T+1 开盘高开 ≥1%”概率更高的形态/因子组合，为提高选股胜率提供可验证依据。

## 背景与问题

现有选股管线以盘中量价 + 基本面过滤为主，未专门研究涨停股次日高开行为。用户希望买入后大概率第二天高开套利，因此需要先回答两个问题：

1. 哪些涨停启动特征（量价、板块热度、价格位置）与次日高开相关？
2. 简单多因子打分能否把胜率从全样本基线显著拉高？

## 范围

本次只做研究和报告输出，不改现有选股/推送逻辑。

## 统计口径

### 股票池

- 沪深主板：`000 / 001 / 002 / 600 / 601 / 603 / 605`。
- 剔除 ST、*ST、退市股。
- 默认最近 1 年日线，参数可扩展。

### 涨停与板型定义

- 涨停：`close >= prev_close * 1.099`（主板 10%，留浮点容差）。
- 首板：当日涨停且前一日未涨停。
- 连板：连续涨停天数 ≥ 2，单独统计，不进策略候选。
- 一字板：`open == high == low == close` 且当日涨停。
  - 策略候选排除（T 日尾盘实际买不到）。
  - 研究报告单列一档观察。

### 买卖与胜率口径

- 买入价：T 日收盘价。
- 卖出价：T+1 开盘价。
- 胜：`open_{T+1} >= close_T * 1.01`（高开 ≥1%）。
- T+1 停牌或无数据：策略统计剔除，报告中标记数量。

## 特征体系

### 量价特征（日线推导）

- 量比：T 日成交量 / 前 5 日均量。
- 振幅：`(high - low) / prev_close`。
- 封板强度近似：
  - 是否收在全天最高（`close == high`）
  - 实体占比：`(close - open) / (high - low)`
  - 是否以涨停价封住
- 价格位置：
  - 相对 MA20 / MA60
  - 距 60 日高点/低点的位置
- 当日成交额（亿元）。

### 板块效应

- 给股票打行业标签（腾讯行业接口，失败自动降级为“未知行业”）。
- 统计同行业当日涨停家数（首板 + 连板都算）作为板块热度。
- 标记是否属于当日涨停家数最多的 3 个行业。

### 基本面过滤（研究阶段）

- 涨停池增强源可用时，按市值区间、换手率区间分桶。
- PE/PB 不作为历史主统计，避免未来函数；只留给后续落地时的当前筛选器。

## 统计方法

- 总样本：N 个首板，输出胜率、平均/中位高开幅度。
- 每个特征分 3-5 桶，输出每桶样本数、胜率、平均高开。
- 单因子排序：按胜率从高到低，每桶最小样本数默认 30。
- 多因子打分：等权 Top 20% 对比全样本的胜率提升。
- 结果输出到 `reports/gap_study_YYYYMMDD.md`。

## 架构

新增独立研究模块 `atrade/research/limit_up_gap/`：

- `labels.py`：涨停/首板/连板/一字板推导，T+1 高开标签。
- `features.py`：量价特征 + 板块热度特征。
- `stats.py`：分桶统计、单因子排序、多因子 Top 20% 对比。
- `report.py`：Markdown 报告渲染。

命令行入口 `scripts/run_gap_study.py`：

```bash
python3 scripts/run_gap_study.py --days 365 --min-samples 30 --min-gap 1.0
```

## 数据流

1. 取沪深主板代码（`ak.stock_info_a_code_name`）。
2. 逐股拉日线（复用 `HistoryProvider` 本地缓存）。
3. 推导涨停/首板/连板/一字板，计算特征与 T+1 高开标签。
4. 板块热度用行业接口 + 本地缓存，失败自动降级。
5. 可选接入东财涨停池历史（`ak.stock_zt_pool_em`）作为增强；实现时先验证历史日期可用性，不可用则只跑日线推导特征。
6. 汇总统计，输出 Markdown 报告。

## 测试

- 涨停/首板/连板/一字板判定。
- 高开胜判定。
- 特征计算（量比、振幅、价格位置、板块热度）。
- 分桶统计与最小样本保护。
- 报告渲染 + 伪造日线的端到端小样本。

## 落地衔接（后续）

如果研究结论支持，下一步设计“每日首板候选 → 早盘推送 → 15:00 高开复盘”，把有效特征接入现有选股管线，并复用已实现的荐股台账。

## 非目标

- 本次不修改现有选股/推送逻辑。
- 不引入实盘下单。
- 不做分钟级回测（尾盘价按收盘价近似）。

## 成功标准

- 不预设胜率门槛，以特征排序和显著性为主要结论。
- 报告可复现、数据有本地缓存。
- 每个统计桶满足最小样本数，避免小样本过拟合。
