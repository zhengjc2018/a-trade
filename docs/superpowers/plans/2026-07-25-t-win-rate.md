# T 胜率优化与每日复盘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通过日线个股趋势、大盘双闸门、按股可配置的 +3% 锁利/-2% 止损和 15:35 每日复盘，减少做 T 误报并量化实际胜率。

**Architecture:** 盘中 5 分钟信号仍由 `SignalEngine` 负责，日线趋势上下文由独立的 `MarketRegimeFilter` 拉取并缓存，避免把 5 分钟 MA20/MA60 误当成日线趋势。`TMonitorRunner` 在候选确认前应用个股与大盘过滤、检查持久化 T 状态并生成优先级更高的锁利/止损告警；`TTradeExecutor` 只负责原子执行、记账和状态提交。持仓是做 T 股票列表的唯一数据源，`monitor.local.json` 的 `symbols[].trailing` 只作为按股阈值覆盖层，网页可直接调整。

**Tech Stack:** Python 3.9、pandas、requests、APScheduler、FastAPI、原子 JSON 文件、pytest、ruff。

## Global Constraints

- 持仓列表始终来自 `holdings.local.json`；`t_monitor.symbols` 不得重新成为独立持仓源。
- 个股趋势使用最近至少 65 根日 K：`MA20 > MA60` 且 `MA20[-1] > MA20[-6]` 才允许 BUY。
- 大盘使用沪深 300（`sh000300`）：`MA20 < MA60` 时屏蔽 BUY；5 日累计跌幅 `< -3%` 时屏蔽普通 BUY/SELL，但不得屏蔽 STOP_LOSS 或追踪止损。
- 大盘行情拉取失败时降级放行并记录 warning，不得中断盘中扫描。
- 追踪阈值按股可覆盖；未填写时锁利默认 `0.03`，止损默认 `0.02`。
- 单股单日只执行一次卖出槽位；锁利或止损必须复用现有防重复机制。
- 15:35 推送当天复盘；无成交也必须推送“今日无已闭环 T 交易”。
- 所有运行状态写入 `data/cache/`，采用临时文件替换，文件损坏时安全恢复。
- 每个任务遵循 TDD：先失败测试，再最小实现，再定向测试和 `ruff check`，然后提交并推送 `origin main` 与 `vps main`。

@dataclass(frozen=True)
class TrendSnapshot:
    symbol: str
    price: float
    ma20: float
    ma60: float
    ma20_slope: float
    drop_pct_5d: float
    trend: str
    fetched_at: str
    data_available: bool = True

class MarketRegimeFilter:
    def get_symbol_trend(self, symbol: str) -> TrendSnapshot:
        return self._get_daily_trend(str(symbol).zfill(6))

    def get_market_gate(self) -> TrendSnapshot:
        return self._get_daily_trend("sh000300")

def allows_signal(signal_type: str, symbol_trend: TrendSnapshot, market_gate: TrendSnapshot) -> tuple[bool, str]:
    signal_type = signal_type.lower()
    if signal_type == "stop_loss":
        return True, "风险退出始终放行"
    if market_gate.data_available and market_gate.drop_pct_5d < -3.0:
        return False, "大盘 5 日跌幅超过 3%"
    if signal_type == "buy":
        if symbol_trend.data_available and symbol_trend.trend != "up":
            return False, "个股日线趋势未向上"
        if market_gate.data_available and market_gate.ma20 < market_gate.ma60:
            return False, "大盘 MA20 低于 MA60"
    return True, "通过趋势过滤"
```

实现细节：使用 `time.monotonic()` + 字典做 300 秒 TTL；按 `close.rolling(20/60).mean()` 计算；少于 65 根或字段异常视为 `data_available=False`；普通信号在数据不可用时放行；`HistoryProvider._to_sina_symbol()` 对 `^(sh|sz)\d{6}$` 原样返回。

@dataclass
class TState:
    symbol: str
    trade_date: str = ""
    status: str = "empty"
    entry_price: float = 0.0
    entry_time: str = ""
    peak_price: float = 0.0
    lots: float = 0.0
    entry_signal: str = ""

class TStateStore:
    def __init__(self, path: Optional[Path] = None):
        self.path = path or DEFAULT_T_STATE_FILE
        self._lock = threading.RLock()

    def get(self, symbol: str) -> TState:
        data = self._read()
        raw = data.get("states", {}).get(str(symbol).zfill(6), {})
        return TState(symbol=str(symbol).zfill(6), **raw)

    def set(self, symbol: str, state: TState) -> None:
        with self._lock:
            data = self._read()
            payload = asdict(state)
            payload.pop("symbol")
            data.setdefault("states", {})[str(symbol).zfill(6)] = payload
            data["trade_date"] = state.trade_date
            self._write(data)

    def mark_buy(self, symbol: str, entry_price: float, lots: float, entry_signal: str, now: Optional[str] = None) -> TState:
        timestamp = now or datetime.now().isoformat(timespec="seconds")
        state = TState(str(symbol).zfill(6), timestamp[:10], "holding", entry_price, timestamp, entry_price, lots, entry_signal)
        self.set(symbol, state)
        return state

    def mark_exit(self, symbol: str, status: str = "empty") -> TState:
        state = TState(str(symbol).zfill(6), datetime.now().strftime("%Y-%m-%d"), status)
        self.set(symbol, state)
        return state

    def reset_day(self, date: Optional[str] = None) -> None:
        self._write({"trade_date": date or datetime.now().strftime("%Y-%m-%d"), "states": {}})
```

写入采用 `.tmp` + `replace()`；根结构保存 `{"trade_date": "YYYY-MM-DD", "states": {"600522": {"status": "holding"}}}`；读取异常记录 warning 并返回空状态。

@dataclass(frozen=True)
class TrailingConfig:
    take_profit_pct: float = 0.03
    stop_loss_pct: float = 0.02
    exit_lots: float = 1.0

@dataclass(frozen=True)
class TrailingAction:
    action: str
    signal_type: str
    price: float
    lots: float
    reason: str

def check_trailing(state: TState, current_price: float, config: TrailingConfig) -> Optional[TrailingAction]:
    if state.status != "holding" or state.entry_price <= 0:
        return None
    lots = min(state.lots, config.exit_lots)
    if current_price >= state.entry_price * (1 + config.take_profit_pct):
        return TrailingAction("take_profit", "sell", current_price, lots, "达到锁利线")
    if current_price <= state.entry_price * (1 - config.stop_loss_pct):
        return TrailingAction("stop_loss", "stop_loss", current_price, lots, "达到止损线")
    return None
```

仅 `holding` 状态判断；达到 +阈值返回 SELL/`take_profit`，达到 -阈值返回 STOP_LOSS/`stop_loss`，卖出手数不超过 state.lots；未触发时只更新 peak 的职责留给调用方，纯函数不得写文件。

class TMonitorRunner:
    def __init__(self, config=None, ttl_hours=DEFAULT_TTL_HOURS, confirmer=None, regime_filter=None, t_state_store=None):
        self.regime_filter = regime_filter or MarketRegimeFilter()

class RoundTrip:
    symbol: str
    name: str
    entry_price: float
    exit_price: float
    shares: int
    pnl: float
    pnl_pct: float
    entry_time: str
    exit_time: str
    entry_factor: str
    exit_factor: str
    holding_minutes: int

def compute_round_trips(trades: list[dict], date: Optional[str] = None) -> list[RoundTrip]:
    trade_date = date or datetime.now().strftime("%Y-%m-%d")
    valid = [item for item in trades if _is_valid_trade(item, trade_date)]
    return _pair_fifo_by_symbol(sorted(valid, key=lambda item: item["timestamp"]))

def compute_stats(trips: list[RoundTrip]) -> dict:
    wins = [trip for trip in trips if trip.pnl > 0]
    losses = [trip for trip in trips if trip.pnl <= 0]
    return _build_stats(trips, wins, losses)
```
